# Filas_AtendimentoCPP2.0

Este projeto é uma implementação em C++ de um sistema de gerenciamento de senhas e guichês, utilizando conceitos fundamentais de Estruturas de Dados, como Filas Dinâmicas e Listas Ligadas.

O sistema permite simular o fluxo completo de um centro de atendimento:

*Geração de Senhas: Criação de senhas numéricas sequenciais que entram em uma fila de espera.
Gestão de Guichês: Abertura de múltiplos postos de atendimento com IDs únicos.
Atendimento Dinâmico: Chamada de senhas por guichês específicos, movendo a senha da fila global para o histórico individual do guichê.
Relatórios: Listagem de senhas atendidas por cada guichê e contador de produtividade total.
Segurança de Dados: Bloqueio de fechamento do sistema caso ainda existam senhas pendentes.*
